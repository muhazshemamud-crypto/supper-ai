# Supper AI

## Publish
1. Upload/extract all files in this folder into a GitHub repository named `supper-ai` (do not upload only the ZIP file).
2. Import that repository at Vercel and deploy.
3. Create a Groq API key from https://console.groq.com/keys.
4. In Vercel open the project → Settings → Environment Variables. Add `GROQ_API_KEY` as the name and paste the key as the value. Save.
5. Open Deployments and redeploy the latest deployment.
6. Open the public Vercel URL and test a chat.

Keep the API key private. This starter supports text chat; file/image analysis, image/video generation, real payments, user accounts and history are not fully implemented. Browser speech-to-text depends on browser support.
